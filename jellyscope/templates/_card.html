{# One card of the registry (jellyscope/cards.py) with its wrapper. Drawn by the Overview (the macro show_card() in video/overview.html) and by a custom dashboard (_dashboard_card.html) - one template, so the two places do not drift apart. The Overview used to have its wrappers by hand and the custom dashboard none, so "Now playing" stood still there and the Movies/Series switch loaded the whole page. Expects `card` (an entry of the registry) and the card's data in the context (cards.data_for). The live wrapper (see cards_base.Card): * `refresh_partial` - the slice is fetched again in the collector's rhythm (data-refresh, data-partial; handled in static/js/app.js). It changes every few seconds, that is why a person comes back here during the day. * `after_sync` - the content redraws itself: when a sync finishes and something was added, this one piece is replaced without reloading the whole page. `data-version` is the library's state at loading - by it a change since then is recognised. * `wrapper_id` - by it the Movies/Series switch finds the card (replaces only it, not the page). Cards of the apps (cards_.py): * `d` - the card's data. They come under the card's key, so cards of several apps in one dashboard do not overwrite each other's variables. The card's template reads only `d.…`. * `prefix` - "Sonarr · " before the card's heading in a dashboard, where cards of several apps can stand side by side. On the app's own page (`in_dashboard` is not set) it is empty - it is clear there whose card it is. Older cards read neither. The card's slot (`card-slot`): one element around the whole card, on every page and in a dashboard, with the card's key and its sources (Card.sources) - an open page finds its cards by it and has them drawn again (/partials/cards, web/dashboards.py). `data-card-period` = the card follows the page's period: over "the last N days" it is drawn anew now and then even when no source moved (static/js/app.js); `data-card-still` = it is not drawn anew by itself on this page (show_card's keep_still). It makes no box of its own (`display: contents` in style.css), so the grid (.grid-2) and a dashboard's cell still lay out the card itself; the rules that reach for a card through its parent name the slot too. The comment with the key before the slot: tests tell the order of cards by it. #} {%- set d = card_data(card.key) %} {#- Flowing right now refreshes itself on the Network page, as it always did; in a dashboard only with Refreshing cards on (Settings → Interface) - it never did there before them, and switched off nothing is to ask more. #} {%- set own_wrapper = (card.wrapper_id or card.refresh_partial or card.after_sync) and not (in_dashboard and card.key == "live_traffic" and not ui_self_refresh) %} {%- set prefix = (_(card.group) ~ " · ") if (in_dashboard and card.group) else "" %} {%- set wrapper_attrs %}{% if card.wrapper_id %} id="{{ card.wrapper_id }}"{% endif %} {#- A card with a period asks with the page's period, not the session's (another tab may have changed it). #} {%- if card.refresh_partial %} data-refresh="{{ poll_interval }}" data-partial="{{ card.refresh_partial }} {%- if card.uses_period and period is defined %}?{{ period.query }}{% endif %}"{% endif %} {%- if card.after_sync %} data-version="{{ library_version }}"{% endif %}{% endset %}
